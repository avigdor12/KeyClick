Metodi di caricamento flessibili per il cliente
Protezione dai duplicati e focalizzazione sui conti
Caricamento di un singolo file: selezione di un file di dati specifico scaricato dalla banca o dalle carte di credito.
Caricamento di un'intera cartella: caricamento simultaneo di tutti i file di dati presenti in una cartella specifica.
Caricamento automatico: il software carica autonomamente tutti i file senza necessità di approvazione separata per ciascuno.
Un gestore file integrato: cliccando su "Carica" si apre un gestore file per una selezione facile.
Un meccanismo di protezione dai duplicati: il software riconosce le transazioni già esistenti e non le aggiungerà due volte. È possibile ricaricare un file già caricato in precedenza con tranquillità, senza timore che i numeri si "gonfino".
Riconoscimento dei numeri di conto: accanto ai pulsanti di caricamento appare un'etichetta "N. conto" estratta automaticamente dai dati.
Selezione dei numeri di conto da visualizzare: le caselle di controllo permettono di scegliere su quali conti concentrarsi e di filtrare fino a 4 diversi conti bancari in parallelo.

Una torta di bilancio viva – regolazione interattiva
Uno strumento unico per la pianificazione di un bilancio equilibrato - le fette di spesa sono mostrate posizionate direttamente sopra la torta delle entrate.
Regolazione dal vivo - una tabella accanto alla torta include cursori intelligenti che permettono di aumentare o diminuire manualmente i valori delle fette.
Raggiungere l'equilibrio - una simulazione in tempo reale che esamina come una modifica in una voce porti a un bilancio completamente equilibrato.

Una bacheca messaggi fissa a 3 livelli
Nella parte inferiore dello schermo, in modo permanente durante tutto il lavoro, si trovano 3 bacheche messaggi separate:
• Messaggi di sistema: indicazioni continue sulle azioni eseguite in background.
• Messaggi guida: suggerimenti, istruzioni e orientamento in tempo reale per eseguire le azioni.
• Messaggi di errore: avvisi chiari in caso di malfunzionamento o file non valido.
Pulsanti disponibili: cancellazione dei messaggi o esportazione dei messaggi in un file esterno.
Ripristino, riavvio e uscita
Se il cliente desidera ricominciare
esistono due pulsanti di ripristino separati e sicuri:
• Ripristina database: elimina tutte le transazioni caricate nel database.
• Ripristina classificazioni: elimina le regole di classificazione apprese e impostate per le transazioni.
• Pulsante Esci: un'uscita ordinata e sicura dall'applicazione con il salvataggio di tutti i dati.
