Flexible Loading Paths for the Customer
Duplicate Protection and Account Focus
Loading a single file: selecting a specific data file downloaded from the bank or credit cards.
Loading an entire folder: loading all the data files located in a specific folder at once.
Automatic loading: the software loads all the files by itself, with no need for separate approval for each file.
A built-in file manager: clicking "Load" opens a file manager for easy selection.
A duplicate-protection mechanism: the software identifies transactions that already exist and won't add them twice. You can reload a file that was already loaded before with peace of mind, without worrying that the numbers will "inflate".
Account number reading: next to the loading buttons, an "Account No." label appears, automatically pulled from the data.
Selecting account numbers to display: checkboxes let you choose which accounts to focus on, filtering up to 4 different bank accounts in parallel.

The Central Table and Data Analysis
A wide matrix: an annual layout
Columns = months
Main table: balance, income and expense totals, previous balance and monthly total
Secondary table: a classification table. Every transaction is classified into one of a fixed list of categories. In this table, each row shows the total for that category.
Classification details: selecting a classification row opens a detail table for that category.
Control Tools, Switches and Export
Important control switches at the top of the screen:
Include Future
Includes or omits future plans and standing orders from the calculation forecast.
Include Credit Cards
Control over including credit transaction details in the overall picture.
Action buttons: Update to refresh the data, Export to save the table as a spreadsheet file or a digital document for printing, plus refresh and clear buttons.

A Learning Classification Engine and System Memory
Automatic organization: the software classifies transactions according to its preset rules as they're imported.
Easy, simple correction: on the classifications screen, an account statement sorted by category, any classification can be changed. The change will be recorded in the system
Smart memory for future loads: when you change a transaction's classification, the system remembers the choice and automatically classifies future transactions with a similar description.
A Dedicated Credit Mechanism
Separation of purchase and billing: handling the time gap between the actual purchase date and the billing date on the bank account.
Payment installments: precise integration of installment transactions within the annual and monthly picture.
A two-tier card display: at the top - a summary table of all the cards. When a card is selected - a bottom table opens with details by billing merchant.

A Fixed 3-Tier Message Board
At the bottom of the screen, permanently throughout your work, there are 3 separate message boards:
• System messages: ongoing updates on actions being performed in the background.
• Guidance messages: tips, instructions and real-time direction for performing actions.
• Error messages: clear alerts in the event of a malfunction or an invalid file.
Available buttons: clearing messages or exporting messages to an external file.
Reset, Restart and Exit
If the customer wants to start over
there are two separate, safe reset buttons:
• Reset Database: deletes all transactions loaded into the database.
• Reset Classifications: deletes the classification rules that were learned and set for transactions.
• Exit Button: an orderly, safe exit from the app while saving all the data.
